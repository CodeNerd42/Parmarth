# 🌿 Parmarth

A socially-driven web application designed and maintained by Parmarth — the official social welfare club of **IET Lucknow**. This platform reflects our mission to promote social awareness, drive change, and engage students in meaningful community service initiatives.

## 🔗 Live Site
👉 [parmarth-drab.vercel.app](https://parmarth-drab.vercel.app)

---

## 📌 Overview

**Parmarth** is a digital hub where students can:
- Explore upcoming social initiatives
- Volunteer for events
- Learn about our past impact
- Engage with the IET social club community

Our website is built to provide a clean and intuitive interface for managing events, showcasing social work, and building a strong student-driven support system.

---

## 🛠 Tech Stack

- **Frontend:** React.js, Tailwind CSS
- **Backend:** Node.js, Express.js (if applicable)
- **Styling:** CSS, Tailwind
- **Deployment:** Vercel

---

## 🚀 Features

- 🧭 Navigation-friendly UI with a mobile-responsive layout  
- 📅 Event listing & details section  
- 📝 Volunteer form (for event registration)  
- 📸 Gallery showcasing our social initiatives  
- 💬 Contact page for collaboration and queries
